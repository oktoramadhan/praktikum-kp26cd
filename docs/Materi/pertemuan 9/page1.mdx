Pada materi-materi sebelumnya, kita telah mempelajari variabel, array, function,
pointer, dan string.

Sejauh ini, satu variabel atau array hanya dapat menyimpan data dengan **satu
tipe data**. Array `int nilai[5]` hanya berisi `int`, sedangkan `char nama[50]`
hanya berisi karakter.

Padahal data di dunia nyata sering terdiri dari beberapa informasi dengan tipe
yang **berbeda-beda**. Data seorang mahasiswa, misalnya:

- Nama → berupa teks (`char[]`)
- NIM → berupa teks (`char[]`)
- IPK → berupa bilangan desimal (`float`)

Untuk mengelompokkan data yang saling berkaitan ini menjadi satu kesatuan, bahasa
C menyediakan **struct** (_structure_).

---

## Tujuan Praktikum

Setelah menyelesaikan praktikum ini, kalian diharapkan mampu:

- Memahami pengertian dan manfaat struct.
- Mendefinisikan struct, membuat variabel struct, dan mengakses member dengan dot operator (`.`).
- Melakukan inisialisasi dan input data ke dalam struct.
- Menggunakan `typedef` untuk menyederhanakan penulisan struct.
- Menggunakan array of struct dan nested struct.
- Menggunakan pointer to struct dan arrow operator (`->`).
- Mengirim struct ke function, baik _by value_ maupun melalui pointer.
- Menyelesaikan permasalahan sederhana menggunakan struct.

## Tahap 1: Mengenal Struct

### Mengapa Butuh Struct?

Misalkan kita ingin menyimpan data dua orang mahasiswa. Dengan pengetahuan yang
kita miliki sekarang, kita mungkin akan menulis seperti ini:

```c
char nama1[50] = "Budi Santoso";
char nim1[15] = "2600001";
float ipk1 = 3.75;

char nama2[50] = "Siti Aminah";
char nim2[15] = "2600002";
float ipk2 = 3.90;
```

Untuk 2 mahasiswa masih bisa. Bagaimana jika 100 mahasiswa? Kita harus membuat
**300 variabel**!

Kalian mungkin berpikir untuk memakai array:

```c
char nama[100][50];
char nim[100][15];
float ipk[100];
```

Cara ini lebih baik, tetapi data seorang mahasiswa masih **tersebar** di tiga
array berbeda. Kita harus selalu ingat bahwa `nama[5]`, `nim[5]`, dan `ipk[5]`
milik mahasiswa yang sama. Jika salah menukar urutan satu array saja, data
mahasiswa akan tertukar.

Dengan struct, seluruh informasi satu mahasiswa dikumpulkan dalam **satu
variabel**:

```c
struct Mahasiswa mhs1;   // mhs1 memiliki nama, nim, dan ipk sekaligus
```

### Apa itu Struct?

**Struct adalah tipe data buatan (_user-defined data type_) yang digunakan untuk
mengelompokkan beberapa variabel, yang dapat memiliki tipe data berbeda, ke
dalam satu nama.**

Setiap variabel di dalam struct disebut **member** (atau _field_).

Biar gampang, bayangkan struct seperti **Kartu Tanda Mahasiswa (KTM)**. Setiap
KTM memiliki format yang sama: ada kolom nama, NIM, dan IPK. Format kartu itu
adalah **struct**-nya, sedangkan kartu milik Budi atau kartu milik Siti adalah
**variabel**-nya.

```text
Struct (format kartu)          Variabel (kartu yang sudah diisi)

┌─────────────────────┐        ┌─────────────────────┐
│ Nama : ____________ │        │ Nama : Budi Santoso │
│ NIM  : ____________ │  ───►  │ NIM  : 2600001      │
│ IPK  : ____________ │        │ IPK  : 3.75         │
└─────────────────────┘        └─────────────────────┘
```

Jika pada Week 1 variabel diibaratkan sebagai sebuah kotak, maka struct adalah
**kotak besar yang di dalamnya terdapat beberapa kotak kecil** dengan ukuran
yang bisa berbeda-beda.

### Mendefinisikan Struct

Kita menggunakan keyword `struct` dengan sintaks dasar berikut:

```c
struct StructName {
    dataType member1;
    dataType member2;
    // ...
};
```

Contoh:

```c
struct Mahasiswa {
    char nama[50];   // member pertama, bertipe string
    char nim[15];    // member kedua, bertipe string
    float ipk;       // member ketiga, bertipe float
};                   // WAJIB diakhiri titik koma
```

Nama struct (disebut _tag_) ditulis dengan **PascalCase**, misalnya `Mahasiswa`,
`DataBuku`, atau `TitikKoordinat`.

Definisi struct biasanya diletakkan **di luar dan sebelum** `main()`, agar dapat
digunakan oleh `main()` maupun function lain di dalam program.

:::warning

Definisi struct **wajib diakhiri dengan tanda titik koma (`;`)** setelah kurung
kurawal penutup. Lupa titik koma adalah salah satu kesalahan yang paling sering
terjadi dan dapat menyebabkan pesan _error_ yang membingungkan.

:::

:::info

Mendefinisikan struct **belum membuat variabel apa pun** dan belum memesan
memori. Definisi struct hanyalah **cetakan** (_blueprint_) yang memberi tahu
compiler seperti apa bentuk datanya. Memori baru dipesan ketika kita membuat
variabel dari struct tersebut.

:::

### Membuat Variabel dan Mengakses Member

Setelah struct didefinisikan, kita membuat variabel dengan sintaks:

```c
struct Mahasiswa mhs1;
struct Mahasiswa mhs2;
```

`mhs1` dan `mhs2` masing-masing memiliki member `nama`, `nim`, dan `ipk`
**sendiri-sendiri**. Selama belum diisi, member masih berisi _garbage value_.

Untuk mengakses member, gunakan **dot operator** (`.`):

```c
variableName.memberName
```

```c
mhs1.ipk = 3.75;
printf("%.2f\n", mhs1.ipk);
```

Setiap member diperlakukan **sama persis seperti variabel biasa** sesuai tipe
datanya. `mhs1.ipk` diperlakukan seperti `float`, sedangkan `mhs1.nama`
diperlakukan seperti string (array of char).

:::warning

Member string **tidak bisa** diisi dengan tanda `=` seperti ini:

```c
mhs1.nama = "Budi Santoso";   // ERROR!
```

Seperti yang sudah kita pelajari pada materi String, array tidak dapat diisi
ulang menggunakan assignment. Gunakan `strcpy()` dari `string.h`:

```c
strcpy(mhs1.nama, "Budi Santoso");   // BENAR
```

:::

### Inisialisasi Struct

Selain mengisi member satu per satu, kita dapat memberi nilai awal saat
deklarasi, mirip inisialisasi array dengan `{}`.

**1. Berdasarkan urutan member**

Nilai di dalam `{}` diberikan ke member sesuai urutan pada definisi struct:

```c
struct Mahasiswa mhs1 = {"Budi Santoso", "2600001", 3.75};
```

```text
"Budi Santoso"  → nama  (member ke-1)
"2600001"       → nim   (member ke-2)
3.75            → ipk   (member ke-3)
```

**2. Designated initializer (C99)**

Sebutkan nama member langsung dengan format `.memberName = value`. Urutan
penulisan **bebas** dan kode lebih mudah dibaca:

```c
struct Mahasiswa mhs2 = {.ipk = 3.90, .nama = "Siti Aminah", .nim = "2600002"};
```

**3. Mengisi seluruh member dengan nol**

Member yang tidak diberi nilai akan **otomatis bernilai 0** (untuk string berarti
string kosong). Karena itu kita bisa menulis:

```c
struct Mahasiswa mhs3 = {0};
```

:::note

Menulis string dengan `"..."` hanya diperbolehkan **saat inisialisasi**. Jika
variabel struct sudah dibuat sebelumnya, gunakan `strcpy()`.

:::

### Input Data ke dalam Struct

Kita juga dapat meminta pengguna mengisi struct dengan `scanf()`. Aturannya sama
seperti variabel biasa:

- Member bertipe angka (`int`, `float`, `double`, `char`) **memerlukan** `&`.
- Member bertipe string (array of char) **tidak memerlukan** `&`.

```c
struct Mahasiswa mhs;

printf("Masukkan nama : ");
scanf(" %49[^\n]", mhs.nama);   // nama boleh mengandung spasi

printf("Masukkan NIM  : ");
scanf("%14s", mhs.nim);

printf("Masukkan IPK  : ");
scanf("%f", &mhs.ipk);
```

Mari perhatikan baris pentingnya:

- `[^\n]` adalah **scanset** yang sudah kita pelajari pada materi String. Ia membaca semua karakter sampai bertemu _newline_, sehingga nama yang mengandung spasi tetap terbaca utuh.
- Angka `49` membatasi jumlah karakter agar tidak melebihi `nama[50]` (1 tempat disisakan untuk `\0`).
- Spasi sebelum `%` berfungsi **melewati** sisa _whitespace_ (termasuk `\n` dari tombol Enter sebelumnya).
- `&mhs.ipk` dibaca sebagai `&(mhs.ipk)`, yaitu **alamat dari member `ipk`**, karena operator `.` berprioritas lebih tinggi daripada `&`.

### Menyalin dan Membandingkan Struct

Berbeda dengan array, variabel struct **dapat disalin** ke variabel struct lain
bertipe sama menggunakan `=`. Seluruh member, **termasuk array di dalamnya**,
ikut disalin sebagai salinan yang benar-benar terpisah:

```c
struct Mahasiswa cadangan = mhs1;   // salinan independen
mhs1.ipk = 4.00;                    // cadangan.ipk tidak ikut berubah
```

Namun, struct **tidak dapat dibandingkan** secara langsung dengan `==` atau `!=`:

```c
if (a == b) { }   // ERROR! Struct tidak bisa dibandingkan langsung
```

Bandingkan **member satu per satu**:

```c
if (a.x == b.x && a.y == b.y) { ... }      // member angka
if (strcmp(a.nim, b.nim) == 0) { ... }     // member string
```

## Tahap 2: typedef dan Array of Struct

Kelas yang kalian kelola ternyata berisi banyak mahasiswa, dan menulis `struct
Mahasiswa` berulang kali terasa panjang. Dua alat berikut akan membantu:
`typedef` dan array of struct.

### typedef

Keyword **`typedef`** memberikan **nama alias** pada sebuah tipe data:

```c
typedef existingType newName;
```

Contoh sederhana:

```c
typedef float Nilai;

Nilai uts = 85.5;   // sama dengan: float uts = 85.5;
```

`typedef` paling sering digunakan bersama struct. Ada dua cara penulisan:

**Cara 1: Tanpa nama tag**

```c
typedef struct {
    char nama[50];
    char nim[15];
    float ipk;
} Mahasiswa;
```

**Cara 2: Dengan nama tag**

```c
typedef struct Mahasiswa {
    char nama[50];
    char nim[15];
    float ipk;
} Mahasiswa;
```

Dengan kedua cara tersebut, kita cukup menulis `Mahasiswa` tanpa keyword
`struct`:

| Tanpa `typedef`                | Dengan `typedef`        |
| ------------------------------ | ----------------------- |
| `struct Mahasiswa mhs1;`       | `Mahasiswa mhs1;`       |
| `struct Mahasiswa daftar[10];` | `Mahasiswa daftar[10];` |
| `struct Mahasiswa *ptr;`       | `Mahasiswa *ptr;`       |

:::tip

Mulai dari bagian ini, contoh program menggunakan `typedef` agar kode lebih
ringkas. Ingat bahwa `typedef` **tidak membuat tipe data baru**, ia hanya
memberi nama lain untuk tipe yang sudah ada.

Pada beberapa kasus, misalnya struct yang memiliki member berupa pointer ke
tipe dirinya sendiri, nama tag (Cara 2) tetap diperlukan.

:::

### Array of Struct

Untuk menyimpan **banyak mahasiswa**, gabungkan array dan struct. Sintaksnya
sama seperti array biasa:

```c
Mahasiswa daftar[3];
```

Baris ini membuat array `daftar` berisi **3 struct** `Mahasiswa`. Setiap elemen
memiliki `nama`, `nim`, dan `ipk` sendiri.

```text
daftar
┌─────────────────┬─────────────────┬─────────────────┐
│    daftar[0]    │    daftar[1]    │    daftar[2]    │
├─────────────────┼─────────────────┼─────────────────┤
│ nama: "Budi"    │ nama: "Siti"    │ nama: "Andi"    │
│ nim : "2600001" │ nim : "2600002" │ nim : "2600003" │
│ ipk : 3.75      │ ipk : 3.90      │ ipk : 3.40      │
└─────────────────┴─────────────────┴─────────────────┘
```

Untuk mengakses member sebuah elemen, gabungkan **indexing** dan **dot operator**:

```c
daftar[1].nama   // nama mahasiswa pada indeks 1 → "Siti"
daftar[2].ipk    // ipk mahasiswa pada indeks 2  → 3.40
```

## Tahap 3: Nested Struct

Sekarang data mahasiswa perlu ditambah **tanggal lahir**. Tanggal terdiri dari
hari, bulan, dan tahun, sehingga lebih rapi jika dibuat sebagai struct
tersendiri. Member dari sebuah struct boleh berupa **struct lain**, dan ini
disebut **nested struct**.

```c
typedef struct {
    int hari;
    int bulan;
    int tahun;
} Tanggal;

typedef struct {
    char nama[50];
    char nim[15];
    Tanggal tanggalLahir;   // struct di dalam struct
    float ipk;
} Mahasiswa;
```

:::note

Struct `Tanggal` harus didefinisikan **sebelum** struct `Mahasiswa`, karena
compiler perlu mengetahui bentuk `Tanggal` terlebih dahulu sebelum digunakan
sebagai member.

:::

Untuk mengakses member dari nested struct, gunakan dot operator **secara
bertingkat**:

```text
mhs.tanggalLahir.tahun
│   │            │
│   │            └── member "tahun" milik tanggalLahir
│   └── member "tanggalLahir" milik mhs (bertipe Tanggal)
└── variabel bertipe Mahasiswa
```

## Tahap 4: Pointer to Struct dan Function

Kalian menyadari bahwa IPK Budi salah diinput dan ingin memperbaikinya lewat
sebuah function. Di sinilah pointer menjadi penting.

### Pointer to Struct

Pada Week 5 dan Week 7, kita telah mempelajari bahwa pointer adalah variabel
yang menyimpan alamat variabel lain. Pointer juga dapat menunjuk ke variabel
bertipe struct:

```c
Mahasiswa budi = {"Budi", "2600001", 3.75};
Mahasiswa *ptr = &budi;   // ptr menyimpan alamat budi
```

```text
   ptr                       budi
┌──────────┐       ┌──────────────────┐
│ &budi  ──┼──────►│ nama : "Budi"    │
└──────────┘       │ ipk  : 3.75      │
                   └──────────────────┘
```

### Mengakses Member melalui Pointer

Kita bisa melakukan _dereference_ terlebih dahulu, lalu memakai dot operator:

```c
(*ptr).ipk
```

Tanda kurung **wajib** ditulis. Karena operator `.` berprioritas lebih tinggi
daripada `*`, tanpa kurung `*ptr.ipk` akan dibaca sebagai `*(ptr.ipk)`, dan ini
menyebabkan _error_ karena `ptr` bukan struct.

### Arrow Operator (`->`)

Karena `(*ptr).ipk` cukup merepotkan, C menyediakan **arrow operator** (`->`)
sebagai cara singkatnya:

```c
ptr->ipk    // sama persis dengan (*ptr).ipk
```

:::tip

Cara mudah mengingat kapan memakai `.` dan kapan memakai `->`:

- Jika yang kalian pegang adalah **variabel struct** → gunakan `.`
  (contoh: `budi.ipk`)
- Jika yang kalian pegang adalah **pointer ke struct** → gunakan `->`
  (contoh: `ptr->ipk`)

:::

### Mengirim Struct ke Function

Struct dapat dijadikan parameter maupun _return type_ sebuah function.

**By value**: function menerima **salinan** seluruh struct, sama seperti
argument lain yang dikirim _by value_ (Week 6).

```c
void perbaikiIpkByValue(Mahasiswa mhs, float ipkBaru) {
    mhs.ipk = ipkBaru;     // hanya mengubah salinan
}
```

**By pointer**: function menerima **alamat** struct, sehingga dapat mengubah data
milik pemanggil.

```c
void perbaikiIpkByPointer(Mahasiswa *mhs, float ipkBaru) {
    mhs->ipk = ipkBaru;    // mengubah data asli
}
```

```text
By value                          By pointer

budi ──(disalin)──► mhs           budi ◄──(alamat)── mhs
  │                  │              ▲
  │                  └─ diubah      └─ diubah langsung melalui mhs->ipk
  └─ tetap 3.07
```

### Returning Struct dan `const`

Function juga dapat **mengembalikan** sebuah struct. Hal ini berguna untuk
"merakit" sebuah data:

```c
Mahasiswa buatMahasiswa(const char *nama, const char *nim, float ipk) {
    Mahasiswa mhs;
    strcpy(mhs.nama, nama);
    strcpy(mhs.nim, nim);
    mhs.ipk = ipk;
    return mhs;
}

void tampilkan(const Mahasiswa *mhs) {
    printf("%s (%s) - IPK %.2f\n", mhs->nama, mhs->nim, mhs->ipk);
}
```

Perhatikan parameter `const Mahasiswa *mhs` pada `tampilkan()`:

- Kita mengirim **pointer** agar seluruh isi struct tidak perlu disalin. Ini lebih efisien, terutama jika struct berukuran besar.
- Keyword `const` menandakan bahwa function **hanya membaca** data. Jika kita tidak sengaja menulis `mhs->ipk = 0;` di dalamnya, compiler akan menampilkan _error_.

:::tip

Pedoman sederhana saat mengirim struct ke function:

| Kebutuhan                          | Bentuk Parameter       |
| ---------------------------------- | ---------------------- |
| Hanya membaca data (struct kecil)  | `Mahasiswa mhs`        |

| Mengubah data milik pemanggil      | `Mahasiswa *mhs`       |

:::

**2. Validasi jumlah mahasiswa**

```c
if (n < 1 || n > MAX_MAHASISWA) {
    printf("Jumlah mahasiswa tidak valid!\n");
    return 1;
}
```

Pengecekan ini mencegah program menulis data di luar batas array `daftar`.

**3. Mengirim alamat elemen array ke function**

```c
inputMahasiswa(&daftar[i]);
hitungNilai(&daftar[i]);
```

`&daftar[i]` adalah alamat elemen ke-`i`. Karena function menerima pointer,
perubahan di dalam `inputMahasiswa()` dan `hitungNilai()` langsung tersimpan ke
array `daftar` milik `main()`.

**4. Menggunakan `->` di dalam function**

```c
mhs->nilaiAkhir = 0.3 * mhs->tugas + 0.3 * mhs->uts + 0.4 * mhs->uas;
```

juga `scanf("%f", &mhs->tugas);`: operator `->` dijalankan lebih dahulu daripada
`&`, sehingga `&mhs->tugas` berarti **alamat dari member `tugas`**, yaitu
`&(mhs->tugas)`.

```c

```

Sama seperti array biasa, yang sebenarnya dikirim adalah alamat elemen
pertamanya. Keyword `const` memastikan function ini hanya membaca data tanpa
mengubahnya.

tertinggi. Dengan indeks tersebut, `main()` dapat mengakses seluruh data
mahasiswa terbaik, tidak hanya nilainya.

## Bonus: Ukuran Struct (sizeof dan Padding)

Bagian ini bersifat tambahan. Kuasai dulu cara mendefinisikan dan menggunakan
struct, array of struct, nested struct, serta pointer to struct.

Kita dapat mengetahui ukuran struct dengan `sizeof()`. Namun, ukuran struct
**tidak selalu sama** dengan jumlah ukuran seluruh member-nya.

```c
#include <stdio.h>

struct ContohA {
    char a;
    int b;
    char c;
};

struct ContohB {
    char a;
    char c;
    int b;
};

int main(void) {
    printf("Ukuran ContohA: %zu bytes\n", sizeof(struct ContohA));
    printf("Ukuran ContohB: %zu bytes\n", sizeof(struct ContohB));

    return 0;
}
```

**Contoh output** pada compiler dan arsitektur yang umum:

```text
Ukuran ContohA: 12 bytes
Ukuran ContohB: 8 bytes
```

Kedua struct memiliki member yang sama (dua `char` dan satu `int`, totalnya
1 + 1 + 4 = 6 byte), tetapi ukurannya berbeda. Mengapa?

Agar CPU dapat membaca data lebih cepat, compiler menyusun member struct pada
alamat memori yang "rapi" (_alignment_). Misalnya, `int` umumnya diletakkan pada
alamat kelipatan 4. Untuk memenuhi aturan itu, compiler menyisipkan byte kosong
yang disebut **padding**.

```text
ContohA (12 bytes)
┌───┬───┬───┬───┬───┬───┬───┬───┬───┬───┬───┬───┐
│ a │ ░ │ ░ │ ░ │ b │ b │ b │ b │ c │ ░ │ ░ │ ░ │
└───┴───┴───┴───┴───┴───┴───┴───┴───┴───┴───┴───┘

ContohB (8 bytes)
┌───┬───┬───┬───┬───┬───┬───┬───┐
│ a │ c │ ░ │ ░ │ b │ b │ b │ b │
└───┴───┴───┴───┴───┴───┴───┴───┘

░ = padding (byte kosong)
```

:::info

Besar padding bergantung pada compiler dan arsitektur. Untuk materi ini, cukup
pahami bahwa ukuran struct **bisa lebih besar** dari jumlah ukuran member-nya.
Karena itu, selalu gunakan `sizeof()` ketika membutuhkan ukuran struct (misalnya
pada `malloc()`), jangan menghitungnya secara manual.

:::

## Bonus: Array of Struct dengan Dynamic Memory Allocation

Bagian ini mengembangkan konsep pointer dan array of struct. Pelajari setelah
memahami materi inti; program berikut memakai `malloc()` dan `free()` untuk
membuat array of struct yang ukurannya ditentukan saat program berjalan.

```c
#include <stdio.h>
#include <stdlib.h>

typedef struct {
    char nama[50];
    float ipk;
} Mahasiswa;

int main(void) {
    int n;

    printf("Jumlah mahasiswa: ");
    scanf("%d", &n);

    // Alokasikan memori untuk n buah Mahasiswa
    Mahasiswa *daftar = malloc(n * sizeof(Mahasiswa));
    if (daftar == NULL) {
        printf("Alokasi memori gagal!\n");
        return 1;
    }

    for (int i = 0; i < n; i++) {
        printf("Nama dan IPK mahasiswa ke-%d: ", i + 1);
        scanf("%49s %f", daftar[i].nama, &daftar[i].ipk);
    }

    printf("\nData yang tersimpan:\n");
    for (int i = 0; i < n; i++) {
        printf("%d. %s - %.2f\n", i + 1, daftar[i].nama, daftar[i].ipk);
    }

    free(daftar);   // kembalikan memori setelah selesai
    daftar = NULL;

    return 0;
}
```

**Output di terminal:**

```text
Jumlah mahasiswa: 3
Nama dan IPK mahasiswa ke-1: Budi 3.75
Nama dan IPK mahasiswa ke-2: Siti 3.90
Nama dan IPK mahasiswa ke-3: Andi 3.40

Data yang tersimpan:
1. Budi - 3.75
2. Siti - 3.90
3. Andi - 3.40
```

`malloc(n * sizeof(Mahasiswa))` memesan memori sebesar `n` kali ukuran satu
struct. Karena `daftar` menunjuk ke awal blok memori tersebut, kita tetap dapat
mengaksesnya dengan indexing seperti array biasa, yaitu `daftar[i].nama`.

:::warning

Jangan lupa memanggil `free()` setelah memori tidak lagi digunakan untuk
mencegah _memory leak_, dan selalu periksa apakah `malloc()` mengembalikan
`NULL`.

:::

## Best Practices

**1. Kelompokkan hanya data yang saling berkaitan**

Struct `Mahasiswa` sebaiknya hanya berisi data milik seorang mahasiswa. Jangan
mencampurkan data yang tidak berhubungan, misalnya jumlah total mahasiswa.

**2. Gunakan nama yang jelas dan konsisten**

Gunakan `PascalCase` untuk nama struct (`Mahasiswa`, `DataBuku`) dan `camelCase`
untuk nama member serta variabel (`nilaiAkhir`, `tanggalLahir`).

**3. Gunakan `typedef` agar kode lebih ringkas**

`Mahasiswa mhs;` lebih mudah dibaca daripada `struct Mahasiswa mhs;`, terutama
ketika struct dipakai berkali-kali.

**4. Pilih cara mengirim struct sesuai kebutuhan**

Gunakan `const StructName *` untuk membaca struct tanpa menyalin seluruh isinya,
dan `StructName *` jika function perlu mengubah data milik pemanggil. Untuk
struct kecil yang hanya dibaca, mengirim by value juga sederhana dan wajar.

**5. Selalu inisialisasi struct**

Gunakan `{0}` atau isi seluruh member sebelum digunakan agar tidak ada member
yang berisi _garbage value_.

**6. Batasi panjang input string**

Gunakan batas lebar seperti `%49s` atau `%49[^\n]` agar input tidak melebihi
ukuran array member.

## Common Mistakes to Avoid

### 1. Lupa Titik Koma Setelah Definisi Struct

```c
// Salah
struct Mahasiswa {
    char nama[50];
    float ipk;
}   // tidak ada titik koma!

// Benar
struct Mahasiswa {
    char nama[50];
    float ipk;
};
```

### 2. Mengisi Member String dengan `=`

```c
// Salah
mhs.nama = "Budi";   // ERROR: array tidak bisa di-assign

// Benar
strcpy(mhs.nama, "Budi");
```

### 3. Lupa Keyword `struct` Tanpa `typedef`

Jika struct didefinisikan **tanpa** `typedef`, keyword `struct` wajib ditulis
saat membuat variabel.

```c
struct Mahasiswa {
    char nama[50];
    float ipk;
};

// Salah
Mahasiswa mhs;          // ERROR: tipe Mahasiswa tidak dikenal

// Benar
struct Mahasiswa mhs;
```

Atau gunakan `typedef` pada definisi struct.

### 4. Tertukar Antara `.` dan `->`

```c
Mahasiswa mhs;
Mahasiswa *ptr = &mhs;

// Salah
mhs->ipk = 3.75;   // ERROR: mhs bukan pointer
ptr.ipk = 3.75;    // ERROR: ptr adalah pointer

// Benar
mhs.ipk = 3.75;    // variabel struct → gunakan .
ptr->ipk = 3.75;   // pointer ke struct → gunakan ->
```

### 5. Membandingkan Struct dengan `==`

```c
// Salah
if (a == b) { ... }

// Benar: bandingkan member satu per satu
if (a.x == b.x && a.y == b.y) { ... }
```

### 6. Lupa `&` Saat Input Member Bertipe Angka

```c
// Salah
scanf("%f", mhs.ipk);    // tanpa &

// Benar
scanf("%f", &mhs.ipk);
```

Ingat bahwa member bertipe string (array of char) **tidak** memerlukan `&`.

## Ringkasan

Pada materi ini, kita telah mempelajari bahwa struct memungkinkan kita
mengelompokkan beberapa data dengan tipe berbeda menjadi satu kesatuan.

Konsep utama yang perlu diingat:

```text
struct
→ Tipe data buatan untuk mengelompokkan beberapa member.

Member
→ Variabel yang berada di dalam struct.

Dot Operator (.)
→ Mengakses member melalui variabel struct. Contoh: mhs.ipk

typedef
→ Memberikan nama alias agar keyword struct tidak perlu ditulis berulang.

Array of Struct
→ Array yang setiap elemennya berupa struct. Contoh: daftar[i].nama

Nested Struct
→ Struct yang memiliki member berupa struct lain. Contoh: mhs.tanggalLahir.tahun

Pointer to Struct
→ Pointer yang menyimpan alamat sebuah variabel struct.

Arrow Operator (->)
→ Mengakses member melalui pointer. ptr->ipk sama dengan (*ptr).ipk

Struct sebagai Parameter
→ By value  : function menerima salinan.
→ By pointer: function dapat mengubah data asli.

Padding
→ Byte kosong tambahan yang membuat ukuran struct bisa lebih besar
  dari jumlah ukuran member-nya.
```

Dengan struct, program menjadi lebih terorganisir karena data yang saling
berkaitan disimpan bersama dalam satu tempat, sehingga lebih mudah dibaca,
dikelola, dan dikembangkan.
